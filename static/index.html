      Questions

      Is CleanSpace a real company?

      No. It is a portfolio demo. Requests are saved only in a local database on this computer.

      How is the estimate calculated?

      Each service line is rate × quantity, rounded to the nearest grosz. The lines are added up; if the sum is below the minimum order value, the difference is added once for the whole order.

      Can I order several services at once?

      Yes — add up to 20 lines to one order, for example home cleaning, a sofa and a carpet.

      Is the preferred time a booking?

      No. It is your wish; the date and time are confirmed separately.

      Where is my data stored?

      Only “Save demo request” sends it to the local server (127.0.0.1), which stores it in a SQLite file. Nothing goes to the internet. Use made-up data.
